# HTML Painter Hotkey

Cycle through **text color** or **highlight color** using keyboard shortcuts in Obsidian.

This plugin lets you assign hotkeys to loop through your favorite colors on selected text. Color cycling is fully customizable via plugin settings.

---

## ✨ Features

- 🎨 Cycle **text colors**: black → red → blue → … → clear
- 🖍️ Cycle **highlight colors**: yellow → cyan → green → … → clear
- ✅ Supports any valid CSS color name or hex code
- 🛠️ User-defined color lists in plugin settings
- 🔁 Keeps text selected between cycles so you can press repeatedly

---

## 🧪 Usage

1. Select any text in your Obsidian note
2. Press your assigned hotkey to:
   - Cycle **text color**
   - OR cycle **highlight background**
3. Repeat to cycle to the next color
4. After the final color, text is cleared (unstyled)

---

## ⚙️ Settings

- Define your own color sequences:
  - `Text Colors`: e.g. `black, red, #0044ff, null`
  - `Highlight Colors`: e.g. `yellow, cyan, #fa8072, #ccff00, null`
- Use `null` to insert a "clear style" step in the loop
- Settings are saved automatically

---

## 🎹 Hotkeys

Go to **Settings → Hotkeys** and assign keys to:

- `Cycle HTML Text Color on Selection`
- `Cycle HTML Highlight (Background Color) on Selection`
